# 次の最小実験 v2：US単独入力＋X-ray風超解像・強調

計画固定：2026-11-14。研究番号なし。利用者が指定した「検査時US単独、MGは研究時の学習・検証参照」に更新する。pilot-v1の凍結ファイル・結果は変更しない。本書は次の実験仕様であり、実行・学習済みではない。

## 目的と主評価

US入力からのクラスター存在検出と、等個数・等総量の配置識別を改善できるか。**X-ray風の高解像度構造mapを生成・US上へsuperimposeし、そのmapもAI解析に使う経路を明示的な比較法として残す。** MGを推論時入力にせず、MG参照にアクセスできない環境でモデルを評価する。

「X-ray風」は石灰化候補を高コントラスト表示するUS座標上の推定mapを指す。実X線の減弱像、測定された石灰化、真の空間分解能向上と同義にはしない。2倍の画素数を得たことを成功基準にしない。

## A. 実データの適格性監査：最優先、最大90分

対象をBCMID v3に固定し、KAU-BCMDを予備1件に限定。[確認記録](PAIRED_DATA_AUDIT.md) を使用する。

1. 現行versionのlicense URI・利用条件、公開metadataとzip内file listを確認する。まず画像取得なしのmetadata。患者ID対応、左右、病変、石灰化ラベル、撮像時期、US画像の原解像度を監査する。
2. metadataで候補を特定できる場合のみ、最大20患者のpaired画像を点検する。患者の抽出規則は正規化patient IDのSHA-256昇順、臨床の正解を見て好都合な例を選ばない。新しい専門家annotationや自動生成した臨床真値を作らない。
3. 部分取得は合計1 GBを上限にする。12.9 GBのBCMID全archiveの取得が必須で部分参照不能なら、今回の監査では画像取得を止め、その制約を報告する。Kaggle認証・申請待ちも待ち時間で実験期限を延長しない。
4. 既存の石灰化有無と同一病変の対応が確認でき、独立患者80例以上（40陽性・40陰性）を構成できる場合だけ、小規模な臨床paired学習を次候補とする。この件数は実行可否のpilot基準であり、臨床有効性の検出力設計ではない。BI-RADSだけの場合は通過しない。

画素registrationがなくても適切な病変対応があれば特徴蒸留は候補になるが、US→実MGのpixel教師学習は行わない。病理がない場合、良悪性分類の真値があるとはしない。正常対照や石灰化陰性が確認できない場合、探索感度・特異度を評価したとはしない。

今回の実データの確認結果がゲート未達なら、臨床学習を開始しない。USCT信号とB-mode臨床画像は別ドメインとして扱い、B-modeの患者対応をUSCTの直接的な外的検証とは呼ばない。

## B. 実データに依存しない機序実験：小規模シミュレーション

MG-USの画素対応問題を避け、同じ潜在石灰化配置からUS計測と高解像度構造mapを作る。これは**合成対応対**であり実患者のpaired検証ではない。実MGの再現・電子密度推定は目的にしない。

### 固定課題と症例

- 2D、HAp、径100 µm、石灰化なし／5個の線状配置／5個の環状配置の3クラス。等個数・等径・等総面積とし、後2者の重心と重心からのRMS距離を一致させる。
- 線状の基準座標(mm)は(−1,0),(−0.5,0),(0,0),(0.5,0),(1,0)。環状は半径sqrt(0.5) mmの正五角形。これは幾何学的配置分類であり、BI-RADSの良悪性・線状分枝状等の臨床分類ではない。
- 各クラス160独立phantom、計480。phantom IDとseedで回転[0,2pi)、重心平行移動x/y各[−2,2] mmを生成する。背景はglandularに固定。背景cの±1%、alpha0の±10%、送信gainの±5%を一様分布でphantomごとに生成し、すべての派生を同一splitに保持する。これらは人工的な頑健性条件で、生体分布の推定ではない。
- 各クラス100 train／30 validation／30 test、乱数seed=20261115で患者に相当するphantom ID単位に先にsplitする。中心・ノイズ・角度違いをtestへ流用しない。testは一度のみ評価、pilot-v1は調整用の開発結果として扱う。
- 1/3 MHz、full32／limited16、参照SNR20/40 dB、計8条件／phantom。装置・pulse・共通絶対noise校正はpilot-v1を維持する。新規SNR探索や径変更をしない。

### 物理・再構成ゲート

pilot-v1の単一中心円柱を、そのまま複数散乱体の正確な解と呼ばない。位置を持つ複数円柱へ拡張する際は、相互散乱を含む円筒調和展開と、単一散乱重ね合わせを固定代表例（両配置・両fc、中心・x=2 mm）で照合する。計測差分の相対L2差5%以下の場合だけ重ね合わせを高速近似として採用する。達しなければ相互散乱解を使い、資源不足なら技術保留とする。独立物理検証を得たとは主張しない。

モード次数16→24、20→40 MHz sample rateで同じ5%基準を適用。従来画像は背景既知の**正則化matched-filter逆投影**1法に固定する。計測をy=(RF−既知背景RF)/sigmaで白色化し、各候補画素の100 µm単一HApテンプレートも同じnoiseとchannelで白色化する。そのL2 normで各列a_jを1へ正規化し、q_j=a_j^T y/(1+lambda)、lambda=1e−3とする。これは各画素の独立した1係数ridge fitであり、全画素を同時推定するFWI／Tikhonov解とは呼ばない。qは無次元scoreで物性画像ではない。固定係数をtestで変更しない。

FOVは8.192 mm、128×128（64 µm pixel）、画素中心は−4.064から+4.064 mm。x/yを上記全画素で評価し、臨床MGのROIを入力しない。表示／ネット入力にはtrainのみから求めた全画像共通の中央値とIQRでscoreを正規化し、[−5,5]へclipする。templateはblock処理、dense行列は保存しない。高解像度構造mapは256×256（32 µm pixel、中心−4.080から+4.080 mm）とする。これにより3経路とも計算量を限定し、反射型の計算score画像を臨床B-modeの再現と取り違えない。

### 3経路の比較：X-ray風超解像を残す

1. **US直接AI**：128×128逆投影score画像から存在と配置を分類する小型CNN。
2. **通常強調**：bicubic 2倍化＋固定unsharp（sigma=1 input pixel、amount=1）で256×256とし、同じ系列の分類器を使う。単なる画素増加・強調の対照。
3. **学習型X-ray風SR**：小型残差encoder/decoderで2倍化し、256×256の石灰化候補mapを生成。2倍化US画像とmapの2channel入力で存在・配置を分類する。mapは同じUS座標に重ねて表示でき、色・コントラスト・overlay opacity=0.35は全test共通。元のUS計測由来画像も同時表示する。

高解像度targetは潜在配置を32 µm pixelへ面積積分したoccupancy mapで、学習時にのみ与える。すべての経路の推論はUSデータだけ。臨床の未登録MGをこのtargetの代わりに置かない。SRは物理的超解像を達成したとの断定を避け、学習型高解像度推定として評価する。

各経路は同一phantom・split・noise条件。学習パラメータ総数各250k以下、単一seed、Adam、lr=1e−3、batch8、最大30epochs、validation loss最良の1checkpoint。分類lossはcross entropy。SR経路のみoccupancy BCEを重み1で追加する。共通のencoder系列を使い、パラメータ数・実行時間差を報告する。GAN・diffusion・外部pretrained model・architecture探索は導入しない。

### 評価と反証

- 主評価：石灰化あり対なしのAUC、validationで設定したFPR5% thresholdでのtest感度・実際のtest FPR。配置分類は石灰化あり例のbalanced accuracyとconfusion matrix。testのnoise条件別、phantom単位bootstrap 1,000回でCIを出す。
- 生成map：位置対応を利用できる合成例のみで病変対応距離150 µm、FP/画像、病変感度を評価する。石灰化なし画像に作る偽点を必ず数える。PSNR/SSIM・見た目は副評価。
- 同一testのSR−US直接、SR−通常強調の差を報告。改善がなくても追加モデルで救済しない。分類が改善してmap偽点が増えた場合は「局在の真実性は改善しない」と分けて結論する。
- 負の対照：同一のnoise-only入力をクラス非依存に与え、ラベル予測がchanceから系統的に外れないか点検する。画像外の文字やIDを入力に含めない。
- RFへ戻せる候補配置について再投影残差を点検するが、小残差だけで解の一意性を証明したとはしない。存在検出から形態復元・悪性診断へ外挿しない。

## C. 実MG教師の導入位置

実データ適格性が通る場合、**training患者のMGだけをteacherにする**。病変対応が確保できる範囲で、石灰化分布descriptor／feature／soft labelをUS studentへ蒸留する。test患者のMGは出力後の参照だけ。studentの入出力契約・推論codeにMGのファイルpathを要求しない。

この蒸留はBの機序実験に混ぜず、実データの病変対応・sample size・teacher仕様を固定した別の小段階とする。今回の上限内でBと実データ本学習の両方を押し込まない。MG教師、SR、ROI選択そのものは新規性とせず、US単独でのタスク改善と偽構造・情報依存性を差分候補にする。
